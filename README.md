# Resume Review Assistant and Interview Preparation Coach

## Objective

The Resume Review Assistant and Interview Preparation Coach is an AI powered career support assistant designed to help users improve resumes, prepare for interviews, optimize ATS compatibility, and generate tailored cover letters.

The assistant simulates realistic interview experiences by asking one question at a time, providing detailed coaching after every answer, and generating a final interview debrief report with readiness scoring and improvement recommendations.

It also helps users tailor resumes to job descriptions by identifying missing keywords, improving technical wording, strengthening resume bullet points, and generating professional cover letters aligned to the target role.

## Prompt 2 — Resume Match & Tailoring

### Prompt
```text
Review my resume against this Information Security Analyst job description.
```

### Output
```text
Resume Match Score: 82%

Strong Matches:
- Vulnerability management
- RMF experience
- Security documentation

Missing Keywords:
- SIEM
- Incident response
- Threat intelligence

ATS Improvement Suggestions:
- Add measurable results to security bullet points
- Improve cloud security wording
```

## Prompt 3 — Proposed Cover Letter

### Prompt
```text

```

```text
Sincerely,
[Your Name]
```
